# Conjugacy-class diameters are eventually affine PORC

A Lean 4 / mathlib formalization project for eventual affine PORC of
Cayley-graph diameters generated by fixed nontrivial cycle types.

**Current status: Theorem 1 is proved.** The formalization includes Lemmas 1–8,
the rational production rate, the generated-group identification, and Remarks
1–3. Both main results depend only on Lean's standard axioms `propext`,
`Classical.choice`, and `Quot.sound`. The project contains no admitted proofs or
custom axioms, and the build checks the main results' dependencies.

## Main result

Fix a nonempty multiset `λ` of cycle lengths, all at least two. Let `C_{λ,n}` be
the permutations in `S_n` with nontrivial cycle type `λ`, let `G_n` be the subgroup
they generate, and let `D_n` be its diameter with respect to this generating class.
Theorem 1 asserts that there are positive integers `P`, `q`, and `N` such that

```text
D_{n+P} = D_n + q    for every n ≥ N.
```

This is the eventual affine PORC property, with common positive
rational slope `q/P`. The main declarations in
[`MainTheorem.lean`](ConjugacyDiametersPORC/MainTheorem.lean) are:

```lean
import ConjugacyDiametersPORC

open ConjugacyDiametersPORC

#check diameter_eventuallyAffinePORC
#check diameter_eventual_recurrence_with_slope
```

The second declaration also identifies `q/P` with `α_λ`, as in Remark 3.

## Build and use

The project pins Lean and mathlib to `v4.35.0-rc3`. With
[elan](https://github.com/leanprover/elan) installed, run from the repository root:

```sh
lake exe cache get
lake build
```

The cache command is useful on a fresh checkout; it needs network access.
The build includes kernel-dependency checks in `Verification.lean`. They fail
if either main result acquires an additional axiom, including `sorryAx`.

Import `ConjugacyDiametersPORC` for the full public entry point, or
`ConjugacyDiametersPORC.Basic` for the definitions alone.
All project declarations live in the namespace `ConjugacyDiametersPORC`.

## Definitions and conventions

`CycleType` stores a nonempty multiset of natural numbers, each at least two.
Its parameter is spelled `lam` in Lean because `λ` is reserved for lambda
expressions. The inventory `m` counts multiplicities, `J` lists the lengths
present, `b` is their sum, `h` is their count, and `d = b - h`.

Permutations act on `Fin n` and compose right to left. Their cycle types omit
fixed points. `C lam n` specifies the full nontrivial cycle type, and `G lam n`
is defined by subgroup closure. Factorizations are ordered lists of generators;
the empty list represents the identity. Inverse closure of the generating class
ensures that every element of the subgroup has such a factorization.

`L` is the natural infimum of the possible factorization lengths, and `D` is
the natural supremum of their values over the finite generated subgroup. The
correctness API establishes nonemptiness, minimality, and attainment. These
definitions apply to every natural degree; degrees too small to realize the
cycle type give a trivial generated subgroup and diameter zero.

`EventuallyAffinePORC` is defined for integer-valued sequences using positive
natural witnesses `P`, `q`, and `N`. The diameter is cast to `ℤ` to apply it.
The witnesses may depend on the fixed cycle type and are independent of `n`.

## Extending the formalization

Keep new definitions in the definitions-only import graph and new results in
their own modules. Reuse the factorization, embedding, and cycle-type APIs when
adding further results. Run `lake build` after changes; the public entry point
imports all project modules, including the dependency checks.
